# Phishing URL Detection

Machine learning models that classify URLs as phishing or legitimate,
evaluated beyond a single random split: cross-dataset testing, realistic
metrics (precision, recall, false positive rate) and error analysis.

## Objectives
- Build a simple baseline, then stronger models, and compare them honestly
- Measure how well models generalize to URLs from a different source
- Analyze the URLs the models get wrong

## Safety
URLs are handled as text only. No suspicious site is ever visited.
